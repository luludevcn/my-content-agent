# SEO Guide

## Keyword Strategy

- Target one primary keyword per article
- Include 3-5 secondary keywords
- Use long-tail keywords for better targeting
- Place keywords naturally throughout the content

## On-Page Optimization

### Title Tags
- 50-60 characters
- Include primary keyword near the beginning
- Make it compelling and clickable

### Meta Descriptions
- 150-160 characters
- Include primary keyword
- Summarize the article
- Include a call to action

### Headers
- H1: Include primary keyword
- H2: Use descriptive headings
- H3: Organize content logically

### Content Optimization
- 1000-3000 words per article
- Keyword density: 1-2%
- Use related keywords naturally
- Include internal links
- Include external links to authoritative sources

## Technical SEO

### URL Structure
- Use lowercase letters
- Use hyphens to separate words
- Keep URLs short and descriptive
- Include primary keyword

### Schema Markup
- Add Article schema
- Add FAQ schema for FAQ sections
- Add Breadcrumb schema

## Content Quality

- Write for users, not search engines
- Provide comprehensive, valuable information
- Use original research when possible
- Update content regularly
- Include multimedia elements (images, videos)

## Internal Linking

- Link to related articles
- Use descriptive anchor text
- Link to pillar pages
- Create a logical linking structure

## User Experience

- Fast page load times
- Mobile-friendly design
- Easy navigation
- Clear content hierarchy
- Readable font sizes
